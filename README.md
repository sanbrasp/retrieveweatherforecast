# About

This is a .NET 10 project from the book 'C# For Dummies All-in-One' by John Paul Mueller. 

The tutorial starts by creating an ASP.NET Core API project, and then an ASP.NET Core Web Application 
project next that communicates with the API project.


The API project can be found here:  
https://gitlab.com/sanbrasp/weatherforecast and here:  
https://github.com/sanbrasp/weatherforecast
